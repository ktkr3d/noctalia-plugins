# Noctalia Plugins

## Plugins

- Jellyfin browser

## Setup plugin Source

1. Open Noctalia settings
   Super + Z
2. Plugins > Sources
3. Add Source
4. Select Git
    - Source ID : ktr3d
    - Location : https://github.com/ktkr3d/noctalia-plugins
5. Add Source

## Setup widget

1. Open Noctalia settings
   Super + Z
2. Bar: default > Widget List
3. Add widget
4. Select widget

## How to Use

- Jellyfin browser
    ```bash
    noctalia msg panel-toggle ktkr3d/jellifin-brower:panel
    ```
    or use widget.
    You can assign a key binding to this command.
